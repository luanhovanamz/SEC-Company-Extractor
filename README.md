# SEC Company Extractor Professional

Desktop application for extracting company information from SEC EDGAR filings.

## Features

- SEC Search API
- Filing Downloader
- Company Information Parser
- Officer Extractor
- Excel Export
- Resume Support
- Cache
- Multi-thread
- Windows Desktop GUI

## Technology

- Python 3.12+
- PySide6
- Requests
- BeautifulSoup4
- OpenPyXL
